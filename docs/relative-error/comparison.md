# 相対誤差型と順位誤差型の向き不向き、マージの概念

DDSketch と HDR Histogram は**相対誤差**を抑える手法である。GK・KLL・t-digest のような順位誤差型の手法とは、保証の性質が違う。この文書は、その違いを、この機能の実験(`runRelativeErrorExperiment`)で測った相対誤差と順位誤差で示す。GK などの実装は呼び出さない。順位誤差型の側は、保証の定義と厳密値から計算できる量で説明する。

数値は `src/relative-error/docs-examples.test.ts` が、固定のシード(1)・最近順位法の基準・ランダムな並び順で同じ実験を実行して照合する。条件は、件数 100,000、分位点 0.5・0.9・0.99・0.999、HDR の範囲は L = 1e−6、H = 1e9、m = 2048 である。

## 二つの保証の違い

| | 相対誤差の保証 | 順位誤差の保証 |
|---|----------------|----------------|
| 定義 | `\|推定値 − 厳密値\| / 厳密値 ≤ α` | `\|推定値の順位 − 目標順位\| / n ≤ ε` |
| 抑えるもの | 値のずれの割合 | 並べたときの順位のずれの割合 |
| 値の大きさ | 桁によらず同じ割合 | 値の大きさと無関係(順位だけを見る) |
| 手法の例 | DDSketch、HDR Histogram | GK、KLL、t-digest(順位の誤差を件数の一定割合以下に抑える) |

順位誤差が小さくても、値が大きく離れていれば相対誤差は大きくなりうる。逆に、相対誤差が小さくても、値が密集していれば順位は大きくずれうる。

## 有利な場面: 重い裾・範囲の広い分布の高い分位点

重い裾の分布(スケール 1、形状 1.5)で、DDSketch(α = 0.01)の推定値の相対誤差と順位誤差を示す。最後の列は、**順位誤差 ε = 0.01 を保証する手法が許す値のずれ**である。順位誤差 0.01 の保証のもとでは、分位点 q の推定値が、順位 q − 0.01 の値であってもよい。その値が厳密値からどれだけ離れているか(`|順位 q−0.01 の値 − 厳密値| / 厳密値`)を、厳密値から計算した。

| 分位点 | DDSketch の相対誤差 | DDSketch の順位誤差 | 順位誤差 0.01 が許す相対誤差 |
|--------|--------------------|--------------------|---------------------------|
| 0.5 | 0.00762 | 0.00546 | 0.0132 |
| 0.9 | 0.0082 | 0.0012 | 0.0617 |
| 0.99 | 0.00678 | 0.00007 | 0.368 |
| 0.999 | 0.00262 | 0.00002 | 0.788 |

- DDSketch の相対誤差は、どの分位点でも α = 0.01 以下である。
- 重い裾では、高い分位点ほど、隣り合う順位の値が大きく離れる。順位誤差 0.01 の保証は、分位点 0.999 で、厳密値より約 79% 小さい値を返しても満たされる。相対誤差の保証は、同じ分位点で 1% 以下を保つ。
- このとき DDSketch の順位誤差も小さい(0.00002)。バケットの幅が値に比例するので、値が疎な高い分位点ではバケットに入る件数が少なく、順位がほとんどずれない。

高い分位点(p99、p99.9 など)のレイテンシを見る用途では、相対誤差の保証が向く。

## 不利な場面: 狭い範囲に値が集中した分布

一様分布(1000〜1010)で、値の比は最大でも 1.01 しかない。DDSketch(α = 0.01、0.05)と HDR(有効桁数 2)の相対誤差と順位誤差を示す。

| 分位点 | DDSketch α=0.01 相対誤差 | 順位誤差 | DDSketch α=0.05 相対誤差 | 順位誤差 | HDR d=2 相対誤差 | 順位誤差 |
|--------|------------------------|---------|------------------------|---------|-----------------|---------|
| 0.5 | 0.00256 | 0.256 | 0.0427 | 0.5 | 0.00046 | 0.0462 |
| 0.9 | 0.00651 | 0.656 | 0.0386 | 0.1 | 0.000264 | 0.027 |
| 0.99 | 0.0074 | 0.746 | 0.0376 | 0.01 | 0.00116 | 0.117 |
| 0.999 | 0.00749 | 0.755 | 0.0375 | 0.001 | 0.00125 | 0.126 |

- どの手法も、相対誤差は上限(α、または 1/256)以下に収まっている。
- しかし**順位誤差は大きい**。α = 0.05 では、データ全体が 1〜2 個のバケットに収まるため、中央値(分位点 0.5)の順位誤差が 0.5 になる。α = 0.01 でも、分位点 0.999 の順位誤差が 0.755 になる。順位誤差 0.01 を保証する手法なら、この分布でも順位のずれは 1% 以下である。
- 値が狭い範囲に集まる分布では、相対誤差の許容値 α が値の幅より粗いと、多くの値が同じバケットに入り、順位の情報が失われる。順位が重要な用途(中央値の順位を正確に知りたいなど)には向かない。

## 使い分けの目安

| 場面 | 向く手法 |
|------|----------|
| 重い裾・範囲の広い分布の高い分位点を、値の割合で正確に知りたい | 相対誤差型(DDSketch、HDR) |
| 値が桁をまたいで広がる(レイテンシなど) | 相対誤差型 |
| 値が狭い範囲に集中していて、順位を正確に知りたい | 順位誤差型(GK、KLL、t-digest) |
| 値の範囲が事前にわからない | DDSketch(値域の制限がない)。HDR は範囲 [L, H] を先に決める |
| メモリを件数や範囲によらず一定に抑えたい | HDR(作成時に固定)、DDSketch(上限 m) |

## マージの概念(実装しない)

複数の sketch を 1 つにまとめる操作を**マージ**という。この機能はマージを実装しない(分散環境でのマージ性能の評価も対象外)。ここでは、バケットの構造がマージにどう効くかを、概念として説明する。

- **DDSketch**: α(したがって γ)が同じ sketch どうしは、バケットの番号が同じ区間を指す。番号ごとに件数を足せば、全データを 1 つの sketch に入れたものと同じ状態になる(縮約が起きていない場合)。縮約が起きたあとの sketch は、足したあとの範囲の長さが m を超えたら、同じ規則(小さい番号の側を合算する)で縮約する。α が違う sketch は、区間が一致しないので、そのままは足せない。
- **HDR Histogram**: L・H・d が同じ sketch どうしは、件数配列の長さと各番号の区間が同じなので、配列の要素どうしを足せばよい。

どちらも、件数を足すだけでマージでき、元のデータを持ち回る必要がない。これは、順位誤差型の手法(サンプルや重心の列を併合して圧縮する)より単純である。ただし、マージしても相対誤差の上限 α(または 1/S)は変わらない一方、縮約が起きた場合は、保証が残る範囲が縮約の影響の上限で決まる点は同じである。
