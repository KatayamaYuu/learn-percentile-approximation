# 誤差指標

推定値と基準値のずれを測る指標は3つある。実装は`src/core/metrics/error-metrics.ts`にあり、`absoluteError`、`relativeError`、`rankError`として公開している。3つとも結果をResult型で返す。absoluteErrorとrelativeErrorは、推定値と厳密値のどちらかが有限の正の数でなければinvalid-valueのエラーを返す。rankErrorは厳密値を引数に取らず、推定値と整列済みデータの先頭と末尾を検査してinvalid-valueを返し、分位点が範囲外ならinvalid-quantile、データが空ならempty-dataを返す。

## 絶対誤差と相対誤差

絶対誤差は|推定値 - 厳密値|である。相対誤差は|推定値 - 厳密値| / 厳密値で、厳密値は正の数なので0で割ることはない。

推定値22、厳密値20の場合、絶対誤差は2、相対誤差は0.1になる。

## 順位誤差

順位誤差は|推定値の順位 - 目標順位| / nである。nはデータの件数で、結果は0以上1未満になる。値の大きさではなく、整列したデータの中でどれだけ順位がずれたかを測る。

### 目標順位

目標順位は定義によらず、常にnearest-rankのceil(n·q)番目とする(percentile-definitions.mdを参照)。ceilの前には、浮動小数点の誤差を取り除く丸め処理を適用する。推定値を出したアルゴリズムが別の定義を使っていても、順位誤差は同じ物差しで比べられる。

### 推定値の順位

整列したデータのうち、推定値より小さい個数をa、推定値以下の個数をbとする。推定値がデータに存在する(b > a)なら、推定値の順位はa+1番目からb番目までの範囲になる。同じ値が複数あるとき、どの順位を選んでも推定値は同じなので、目標順位に最も近い順位を採用する。つまり目標順位をこの範囲に収めた値が推定値の順位になり、目標順位が範囲に入っていれば順位誤差は0になる。

推定値がデータに存在しない(b = a)場合は、推定値より小さい値がa個あるので、順位をaとする。

### 例 データにない推定値

データを[10, 20, 30, 40]、q = 0.5とすると、目標順位はceil(4 × 0.5) = 2である。推定値25の順位は2になる。25より小さい値が10と20の2個だからである。順位誤差は|2 - 2| / 4 = 0になる。推定値35の順位は3になり、順位誤差は|3 - 2| / 4 = 0.25になる。

### 例 同値がある場合

データを[10, 20, 20, 20, 30]とし、推定値を20とする。20より小さい値は1個、20以下の値は4個なので、推定値の順位は2番目から4番目までの範囲になる。

q = 0.5のとき目標順位は3で、範囲に入るため順位誤差は0になる。q = 0.9のとき目標順位は5で、範囲の外にある。範囲内で最も近い4番目を推定値の順位とする。順位誤差は0.2になり、計算式は|4 - 5| / 5である。
