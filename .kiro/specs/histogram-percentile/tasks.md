- [ ] 1. 基盤: バケット境界の指定と検証
- [x] 1.1 境界の指定のエラー型と、3種の境界列の生成・検証を実装する
  - 境界の指定の誤りを表すエラーと、実験条件の誤りを表すエラー(境界の誤り、実験条件の誤り、データ生成の失敗、ハーネスの入力エラーを区別する)を判別できる型で定める
  - 等幅、指数幅、任意境界の3種から境界列を作る。等幅は幅が一定、指数幅は隣り合う境界の比が一定になるようにし、先頭と末尾は指定値そのものにする。任意境界は指定の列を複製して保持する
  - 次の指定はエラーにして、境界列を作らない: 有限の正の数でない下限・上限、下限が上限以上、バケット数が1以上かつ上限以下の整数でない、任意境界が2個未満または狭義単調増加でない、丸めで隣り合う境界が区別できなくなる指定、未知の種類。エラーには原因の項目を含める。バケット数の上限は10万とする
  - 完了時の状態: 3種それぞれの境界列の単体テストが通る(幅・比の一定、端点が指定値に等しい、列の複製)。上のエラー区分がすべて、期待した原因の項目つきで返ることのテストが通る

- [ ] 2. 領域部品: 線形補間による推定とヒストグラム本体
- [x] 2.1 (P) バケットの件数列から分位点を線形補間で推定する関数を実装する
  - 目標順位は共通基盤の最近順位法の丸め規則で決め、先頭から累積件数を足して、累積件数が初めて目標順位以上になるバケットを選ぶ
  - 選んだバケットの下側の境界から上側の境界までを、(連続の目標順位 − そのバケットより前の累積件数) ÷ そのバケットの件数 の割合で補間する。連続の目標順位は件数 × 分位点を、前の累積件数以上・そのバケットの累積件数以下に収めた値とし、推定値は選んだバケットの閉区間に収める。分位点 0 は最初の非空バケットの下側の境界になる
  - 調べたバケットごとに比較を1回数える。移動、累積の加算、補間の四則演算は数えない
  - 境界列は共通基盤の境界生成に依存せず、直接用意した配列でテストする
  - 完了時の状態: 等幅(下限10、上限50、4バケット)に値 15、25、25、35 を入れた件数列で、分位点 0、0.25、0.5、0.75、1 の推定値が 10、20、25、30、40 になるテストが通る。全件が1つのバケットに入る場合、空のバケットをまたぐ場合、`0.07 × 100` のように丸めで整数からずれる分位点でも選択がずれない場合、問い合わせの比較回数が選んだバケットの位置 + 1 になることのテストが通る
  - _Boundary: Estimate_
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 3.7, 4.3_

- [x] 2.2 固定バケットのヒストグラムを、共通規約に従うアルゴリズムとその生成仕様として実装する
  - 境界の指定から、バケットごとの件数と総件数を保持するアルゴリズムを作る。境界の指定が不正なら作らずにエラーを返す
  - 投入: 不正な値は値の誤りで拒否し、先頭の境界未満または末尾の境界より大きい値は扱えない値として拒否する。いずれも状態・操作数・メモリ見積もりを変えない。区間は下側の境界を含み上側を含まず、最後のバケットだけ両端を含む
  - バケットの特定: 等幅・指数幅は計算で求めた添字を境界の配列と比べて補正し、実行した比較だけを数える。任意境界は二分探索で、実行した比較だけを数える。投入1回の移動は、バケットの件数と総件数の2回と数える
  - 問い合わせ: 分位点の範囲を先に、空かどうかを次に検査してエラーを返し、成功時は線形補間による推定値を返す。乱数は使わず、シードは受け取っても使わない
  - メモリ見積もりは、境界の個数と、バケット件数 + 総件数のカウンタ個数だけから求め、件数に依存させない。初期化は件数と操作数を戻し、境界を保つ
  - 生成仕様には、識別子(既定は種類とバケット数から作り、上書きできる。範囲は含めない)、表示名、パラメータ(境界の決め方、バケット数、先頭と末尾の境界)、扱える値の範囲(先頭の境界以上、末尾の境界以下)を持たせる
  - 完了時の状態: 区間の包含(下側の境界は含み、上側の境界は次のバケット、最後のバケットは上側も含む)、範囲内の投入が問い合わせの結果に反映されること、範囲外・不正な値・範囲外の分位点・空の問い合わせのエラーと状態不変、同じ入力での同じ推定値・操作数・メモリ見積もり、初期化後が新規作成直後と同じこと、パラメータが記録として有効であることの単体テストが通る
  - _Depends: 1.1, 2.1_
  - _Requirements: 1.5, 1.6, 1.7, 1.8, 1.9, 2.1, 2.3, 2.4, 2.5, 3.8, 3.9, 4.1, 4.2, 4.4_
